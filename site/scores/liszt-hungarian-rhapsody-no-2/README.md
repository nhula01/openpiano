# Hungarian Rhapsody No. 2

Composer: Franz Liszt
Transcription: King Feraligatr on MuseScore, released under Public Domain Mark
Source: https://musescore.com/the-most-intelligent-and-musical-pokemon-in-the-universe/scores/2577171 (via the PDMX public-domain MusicXML dataset, https://zenodo.org/records/15571083)

`original.mxl` is the transcription, bundled unchanged. The practice data
(`practice.json.gz`) is engraved from it with Verovio: hidden playback-only notes (145
in this file) are left out, tied notes sound once, hands follow the staff each note is
printed on.
This transcription has no fingerings, and none are generated.
