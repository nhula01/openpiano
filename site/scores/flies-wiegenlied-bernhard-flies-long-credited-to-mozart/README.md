# Wiegenlied (Bernhard Flies, long credited to Mozart)

Composer: Bernhard Flies
Transcription: Phill Columbulus on MuseScore, released under Public Domain Mark
Source: https://musescore.com/user/3211221/scores/962866 (via the PDMX public-domain MusicXML dataset, https://zenodo.org/records/15571083)

`original.mxl` is the transcription, bundled unchanged. The practice data
(`practice.json.gz`) is engraved from it with Verovio: hidden playback-only notes (0
in this file) are left out, tied notes sound once, hands follow the staff each note is
printed on.
This transcription has no fingerings, and none are generated.
