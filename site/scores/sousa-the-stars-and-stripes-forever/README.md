# The Stars and Stripes Forever

Composer: John Philip Sousa
Transcription: clothesliner on MuseScore, released under Public Domain Mark
Source: https://musescore.com/user/1461451/scores/1014656 (via the PDMX public-domain MusicXML dataset, https://zenodo.org/records/15571083)

`original.mxl` is the transcription, bundled unchanged. The practice data
(`practice.json.gz`) is engraved from it with Verovio: hidden playback-only notes (0
in this file) are left out, tied notes sound once, hands follow the staff each note is
printed on, and repeats are written out in performed order.
This transcription has no fingerings, and none are generated.
