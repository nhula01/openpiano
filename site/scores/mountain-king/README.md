# In the Hall of the Mountain King · piano version

Composer: Edvard Grieg
Typesetting: Coyau
License: Public Domain
Source: https://www.mutopiaproject.org/cgibin/piece-info.cgi?id=1888

Original PDF and LilyPond source are bundled unchanged. The practice source is
converted to LilyPond 2.24, with repeats unfolded and tagged noteheads added.
Printed fingerings are retained directly from that edition; no generated
fingerings are added. The player derives attacks and durations from the
compiled MIDI and assigns hands from the two MIDI staff tracks.

This engraving and practice data inherit the source license.

Notes for this score: Practice copy: the three-note grace runs use \grace with a slur instead of \appoggiatura, because LilyPond’s MIDI plays an appoggiatura on the beat while the printed runs come before it.
